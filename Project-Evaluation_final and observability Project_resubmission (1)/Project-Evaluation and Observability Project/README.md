Evidence Package — Recommended Submission Layout

Organize your final submission as a single folder (or compress it into a ".zip" file) using the structure below. Complete "reflection-brief.md" as you progress through the work so your observations and evidence are recorded immediately after each run rather than reconstructed later.

Locations of the Completed Systems

The finished reference implementations are included in the course repository ("cd15552 Claude AI Engineer Evaluation and Observability"). Each system should be executed from the solution/ directory of its final exercise. The corresponding starter/ directories are only for practice and are not intended for the final capstone execution.

Inside each "solution/" folder, install the project using:

"pip install -e ".[dev]""

This makes the associated command-line tool available on your system.

Both plain text files (".txt") and screenshots are acceptable as supporting evidence. The essential requirement is that every value or observation referenced in the reflection brief can be verified directly by opening the corresponding artifact.

Perturbation Log

A template file named "perturbation-log.md" is included with a dedicated section for each system. For every system, intentionally modify either an input or configuration, state your expected outcome, execute the system, and document the actual behavior that occurred.

Suggested experiments include the following, although you may create your own variations for additional originality:

- Policy Pipeline: Remove or leave blank a mandatory field within one policy document so the required information is unavailable. Verify that the pipeline escalates the case appropriately, avoids fabricating missing data, and performs only a single API request.
- Mortgage Extraction: Change the reported total so it no longer matches the sum of the individual line items. Confirm that the mathematical consistency validator identifies and reports the discrepancy.
- Supply Chain Investigation: Execute the workflow with the "--simulate-timeout" option enabled. Verify that the unavailable source is clearly marked as Incomplete while the remaining investigation continues successfully to completion.
